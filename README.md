# NHAI EdgeFace Secure

Offline facial recognition and liveness verification module for NHAI DataLake 3.0.

Features:

- Offline recognition
- Liveness detection
- Anti spoof checks
- Visitor handling
- Temporary enrollment
- Local encrypted storage
- AWS sync
- Purge mechanism

Tech Stack:

Frontend:
React Native

AI:
BlazeFace
MobileFaceNet
MediaPipe
FAISS

Storage:
SQLCipher SQLite

Cloud:
AWS S3
AWS DynamoDB
